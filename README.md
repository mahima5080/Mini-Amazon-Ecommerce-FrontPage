# Mini Amazon — E-Commerce Front Page (Web Development Week 4 Capstone)

## 📌 Project Overview
This repository contains the **Week 4 Web Development Capstone Project**. The application is a fully interactive, responsive **E-Commerce Front Page ("Mini Amazon")** built using **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**.

---

## 🛠️ Key Features & Capabilities

1. **Home Page & Product Grid**:
   * Responsive multi-column product layout featuring ratings, pricing, and category tags[cite: 43].
   * Category filtering (Electronics, Fashion, Home & Kitchen, Books) and real-time product search[cite: 43].

2. **Product Details Popup Modal**:
   * Interactive modal window presenting detailed descriptions, feature highlights, customer ratings, and direct "Add to Cart" controls[cite: 43].

3. **Persistent Shopping Cart (`localStorage`)**:
   * Interactive cart sidebar displaying itemized quantities, price breakdowns, subtotals, tax calculations, and grand totals[cite: 43].
   * Full data persistence across browser reloads using HTML5 `localStorage`[cite: 43].

4. **Cart Page & Checkout Simulation**:
   * View full cart page with quantity increment/decrement controls, item removal, and an interactive simulated order checkout[cite: 43].
